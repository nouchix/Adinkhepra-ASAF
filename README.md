## 🛠️ Quickstart

### Prerequisites
- Node.js 20+ / npm 10+
- Go 1.23+ (for compiling sovereign Go binaries)
- Modern web browser (Chrome, Edge, Firefox, Safari)

### 1. Launching the Web Console Locally
```bash
# Clone the repository
git clone https://github.com/nouchix/Adinkhepra-ASAF.git
cd Adinkhepra-ASAF

# Install dependencies (Next.js 16 + Tailwind CSS)
npm install

# Run development server with Turbopack
npm run dev

# Open console in browser
open http://localhost:3000
```

### 2. Compiling Sovereign Go Engines
```bash
# Compile AdinKhepra CLI
go build -ldflags="-s -w" -o bin/adinkhepra.exe ./cmd/adinkhepra

# Compile REST & SSE API Server
go build -ldflags="-s -w" -o bin/apiserver.exe ./cmd/apiserver

# Compile KASA Runtime Agent
go build -ldflags="-s -w" -o bin/agent.exe ./cmd/agent
```

### 3. Running an ERT Analysis & Serving the Graph
```bash
# Run full ERT analysis against local directory
./bin/adinkhepra.exe ert full .

# Launch local Living Trust Constellation viewer
./bin/adinkhepra.exe serve -port 8080
```
